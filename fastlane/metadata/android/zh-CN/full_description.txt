DSH Mobile 是 DeepSeek Harness（dsh）自主编程 Agent 系统的官方开源移动端客户端。

主要功能：
• 实时 Agent 追踪：实时查看 Agent 的多轮思考、工具调用、Bash 命令执行与执行结果。
• 交互式安全审批：在手机上直接查看并审批沙箱高危操作（文件修改、Shell 命令、子 Agent 派发等）。
• 灵活连接后端：通过 HTTP 与 WebSocket 直连私有部署或远端的 dsh web 服务端。
• 目标与会话管理：创建、继续、暂停和管理长生命周期自主目标（Goal）与复杂任务。
• 本地语音输入：集成端侧离线语音识别，支持快捷语音输入指令。
• 纯正 Material 3 体验：深度遵循 Material 3 设计标准，支持流畅的浅色与深色主题切换。
• 完全开源自由：采用 MIT 开源许可证，不含任何专有跟踪分析或闭源 SDK。
